# GLOBAL TRAINING CENTER v2.1 · 전국 인증도장 네트워크

기존 v1.0의 구조와 기능을 유지하면서 다음을 추가했습니다.

- GLOBAL TRAINING CENTER 로고 적용
- IPMA / WTKF / 국제드론순찰대 실제 로고 적용
- 메인 메시지: OPEN TRAINING FOR EVERYONE
- 호신술·경찰무도 전문 훈련관
- 태권검도 전문 훈련관
- 드론순찰 전문 훈련관
- 각 분야별 6개 교육 ROOM
- Google Drive 교본 링크 연결용 교본 썸네일 공간
- YouTube 영상 링크 연결용 영상 썸네일 공간
- 모바일 반응형
- 기존 공통교육, 시뮬레이터, 시험·인증, MY TRAINING, 지도자센터 유지
- 기초교육 무료 공개 + 공식 지도권한 자격제 구조로 개편
- 어린이 통합무도·태검·생활호신술·더블크로스 지도자과정 추가
- 과정별 사전등록 신청 페이지 및 수파베이스 접수 연결 추가
- 사단법인 국제경찰무도연합회 주관 표시 강화

## 최초 적용 순서

1. 수파베이스 SQL Editor에서 `admin/SUPABASE-GTC-COURSE-APPLICATIONS.sql` 실행
2. 전체 파일을 GitHub 저장소에 업로드
3. `apply.html`에서 테스트 신청 1건 접수
4. 지도자 과정별 교육기간·검정료·자격증 발급비·합격기준 확정

## v2.1 핵심 사업원칙

- 태검·어린이 생활호신술·경무 기초·더블크로스를 어린이 통합무도 프로그램으로 구성
- 배워볼 수 있는 기초교육은 무료 공개
- 정식 지도권한은 교육 이수와 검정·심사를 통과한 지도자에게만 부여
- 공인 지도자가 있는 도장은 가입비·연회비 0원 인증정책 검토
- 인증도장에서 학생등록·수련·심사·공식 단증 발급 연결
- 핵심 성장지표: 활성 인증도장 수 × 수련생 수 × 심사 참여율

현재 버전은 지도자 과정과 인증도장 신청자를 확보하는 1단계입니다. 다음 단계에서 지도자 검정, 자격증, 학생등록, 심사와 단증 발급 시스템을 연결합니다.
